High-yield cheat sheet

The exam is closed book. These are the rules the questions keep testing, pulled from the slides, lectures, Ed posts and the sample key.

ggplot2 grammar

  • Layer = geom + aes mapping + data + stat + position.
  • Building blocks: Layers (unlimited), Scales (one per aesthetic mapping), Coord (one), Facet (one), Theme (one, sort of).
  • Mapping = inside aes() → gets a scale/legend. Setting = constant outside aes (color = "grey50", alpha = .5) → no scale.
  • Continuous = num/dbl/int; discrete = fct/chr/lgl. Numeric 0/1 → gradient; use factor().
  • geom_bar() = stat count (1 column); geom_col() = stat identity (x & y). Default histogram bins = 30.
  • y = after_stat(density) → density histogram. color = borders/lines/points; fill = areas.
  • End lines with +. Positions: identity, jitter, dodge (grouped), stack, fill (proportions).

Histograms

  • Look for: asymmetry, outliers, multimodality, gaps, heaping/rounding, impossible values (999, −2 codes = missing).
  • Prefer binwidth; set boundary or center, or all breaks.
  • Default right-closed (a, b]: value on boundary goes LEFT. closed = "left" → [a, b).
  • density = rel. freq / binwidth; bar area = rel. freq; total area = 1.
  • Unequal binwidths → use density (the "27 vs 6 year olds" trap: 4:1 looks → 2:1 real).
  • Bimodal heights → two groups (men/women).

Boxplots & quantiles

  • Show median, hinges, whiskers, outliers. Can't show mean, n, or modality.
  • H-spread = upper − lower hinge. Fences = hinges ± 1.5 × H-spread. Whiskers → most extreme points inside fences.
  • Base R/Tukey: hinges (fivenum; odd n → median in both halves). ggplot2: quartiles (quantile type 7) + IQR.
  • Type 7: h = (n−1)p, interpolate. 10…80 → Q1 = 27.5.
  • Varwidth ∝ √n. Odd boxes (no whiskers, median on edge) → small n and/or discrete values.
  • Outliers → investigate, don't auto-delete.

Density, ridgelines, QQ, normality

  • Larger bandwidth → smoother; smaller → bumpier. Gaussian kernel; bw ≈ σ.
  • Area under a density curve = 1 (heights can exceed 1).
  • Ridgelines show modes better than boxplots (pulsar / Joy Division).
  • QQ (theoretical on x): straight = normal; convex "smile" = right skew; concave "frown" = left skew; S steep ends = heavy tails; flat ends = light tails (uniform).
  • Shapiro–Wilk H₀ = normal. p = .65 → cannot reject normality (not "65% chance normal"). W ∈ [0,1]; p depends on W and n.
  • Stem-and-leaf: read the decimal-point line. All leaves 0/5 → rounding.

Categorical & missing data

  • Nominal → sort by frequency (fct_infreq); ordinal → logical order; numbers can be nominal (zip codes).
  • chr → alphabetical; factor → level order. factor(x, levels=…) must match exactly (else NA). Don't set order with levels()<-.
  • forcats: reorder (by y, dot plots), reorder2 (lines), rev (horizontal bars), relevel (by hand), lump_n (+Other), na_value_to_level.
  • Cleveland dot plot: position encoding, no zero baseline needed; bars need zero.
  • Topcoding ("or more") OK if few values in top bin (Q4 corrected key).
  • NA: ggplot keeps NA bar; explicit NA level → is.na() FALSE. drop_na()/na.omit() = complete cases; drop_na(col) only that column. "N/A" string ≠ NA.

Scatterplots, 2D density, facets

  • Overplotting: open circles, alpha, smaller points, sample, subset, log scale, heatmaps/contours.
  • x & y only: geom_bin_2d, geom_hex, geom_density_2d. Need z: geom_contour, geom_tile (fill).
  • ntile = equal counts; cut = equal widths.
  • Scatter features: associations, outliers, clusters, gaps, barriers, conditional relationships. Gridlines help read values, hurt pattern-spotting.
  • Facets = small multiples/panels/trellis/lattice. Keep shared scales, except facet-per-variable → scales = "free_x".
  • Same panel = easiest comparison. Categorical → color/facets/shape; continuous → x/y.

Parallel coordinates

  • Line = case, axis = variable. Parallel lines = +corr; crossing X = −corr; only adjacent axes compare easily.
  • Best for following cases across many continuous variables (movies top on all 3 → PCP).
  • ggparcoord scale: std (default, (x−mean)/sd), uniminmax ([0,1] per variable), globalminmax (original units).
  • Rescaling each axis to 0–1 hides which variables are high overall (Q24).
  • geom_line version: pivot_longer + group = id. alphaLines, splineFactor, groupColumn; parcoords = interactive.

Mosaic & multivariate categorical

  • Area ∝ frequency of each combination; tiles = product of levels (2×2×5 = 20). Not a treemap.
  • Dependent variable: split last, horizontally, = fill. Others vertical (3 vars: V V H; 4 vars: H V V H).
  • Most-interest level: bottom, darkest. Least interest: top, lightest (Q17).
  • Aligned cuts = independence; staircase = association. Pairs plot: biggest staircase wins.
  • Earlier split = contiguous labeled blocks; later variables repeat within blocks.
  • vcd: mosaic(dep ~ a + b, direction = c("v","v","h"), highlighting_fill = …) → splits a, b, then dep. Colors = # levels of dep.
  • Grouped bars = read frequencies; mosaic = association (Q25). Stacked bars: totals & bottom easy, top/middle hard.
  • Same-binwidth mosaic = proportion stacked bar (position = "fill"), but loses counts.
  • Expected (independence) = row total × col total / N; χ² compares observed vs expected.
  • Simpson's paradox (airlines/airports): mosaic tile sizes reveal the lurking variable.
  • Diverging stacked bar: ordinal/Likert with polar ends; drop "neutral" if it means "don't know".
  • pivot_longer: rows = r × (# pivoted cols); cols = kept + 2. Cases → counts: group_by + summarize.
